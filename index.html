Các Bước Cài Đặt Chi Tiết

Hướng dẫn từng bước cấu hình MCP IMAP Server vào Claude Code CLI trên máy của bạn

Bước 1: Chuẩn bị App Password (Ứng Dụng Mật Khẩu)

Bảo Mật Yêu Cầu

Hầu hết các dịch vụ email hiện đại (Gmail, Outlook, Yahoo) không cho phép đăng nhập trực tiếp bằng mật khẩu tài khoản chính qua IMAP mà yêu cầu App Password (Mật khẩu ứng dụng) hoặc kích hoạt 2FA.

Gmail / Google Workspace
  • Bật Xác thực 2 bước (2-Step Verification) trong Google Account.
  • Truy cập: myaccount.google.com/apppasswords
  • Tạo App Password mới (Ví dụ chọn app tên "Claude MCP").
  • Lưu chuỗi 16 ký tự (Ví dụ: abcd efgh ijkl mnop).
Outlook / Office 365
  • Truy cập account.live.com/proofs/manage/additional
  • Cuộn xuống phần App passwords.
  • Chọn Create a new app password.
  • Sử dụng mật khẩu vừa tạo làm giá trị cho IMAP_PASSWORD.

Bước 2: Cài Đặt hoặc Sử Dụng MCP IMAP Server Package

Node.js / npx

Có nhiều MCP IMAP package sẵn có trong cộng đồng open-source (như @mcp-servers/imap hoặc imap-mcp-server). Bạn có thể chạy trực tiếp bằng npx mà không cần cài đặt cố định.

Cách 1: Chạy trực tiếp thông qua npx (Khuyên dùng)
npx -y @gongaza/mcp-imap-server
Cách 2: Cài toàn cục (Global CLI)
npm install -g @gongaza/mcp-imap-server

Bước 3: Cấu hình File `claude.json` / MCP Config

Config JSON

Claude Code CLI lưu trữ danh sách các MCP Server trong file cấu hình người dùng. Thêm khối mcpServers vào file cấu hình của Claude.

Vị trí file cấu hình Claude Code:
  • macOS/Linux: ~/.claude.json hoặc ~/.config/claude/claude.json
  • Windows: %APPDATA%\Claude\claude.json

Bước 4: Khởi Động Claude Code & Kiểm Tra

Test Run

Mở Terminal, khởi chạy Claude Code CLI và kiểm tra xem danh sách tools của IMAP đã sẵn sàng chưa bằng câu lệnh trợ giúp hoặc kiểm tra mcp tools.

// Khởi động Claude Code trong dự án của bạn:
$ claude
// Trong phiên làm việc với Claude, thử gõ:
/mcp

-> Bạn sẽ thấy MCP Server imap-mail ở trạng thái Connected cùng danh sách các tool như imap_search, imap_fetch, imap_list_mailboxes.

Trình Tạo Cấu Hình MCP Config (`claude.json`)

Điền thông tin mail server của bạn để tự động sinh file JSON chuẩn

Mẫu nhanh:
Lưu ý: Mật khẩu hiển thị ở đây chỉ để tạo cấu hình mẫu trên trình duyệt của bạn. Hãy đảm bảo giữ bảo mật file claude.json thực tế.
File: claude.json 
{
  "mcpServers": {
    "imap-mail": {
      "command": "npx",
      "args": [
        "-y",
        "@gongaza/mcp-imap-server"
      ],
      "env": {
        "IMAP_HOST": "imap.gmail.com",
        "IMAP_PORT": "993",
        "IMAP_TLS": "true",
        "IMAP_USER": "ban.email@gmail.com",
        "IMAP_PASSWORD": "abcd1234efgh5678"
      }
    }
  }
}

Bảo Mật Quyền Riêng Tư

MCP IMAP Server chạy cục bộ (Local Stdio) trên máy tính của bạn. Mật khẩu email không bao giờ được gửi tới máy chủ bên thứ ba.

Không Dùng Mật Khẩu Chính

Luôn luôn tạo App Password riêng cho Claude Code. Nếu nghi ngờ rò rỉ, bạn có thể thu hồi mật khẩu ứng dụng này bất cứ lúc nào mà không ảnh hưởng tới tài khoản gốc.

Chế Đồ Đọc (Read-Only)

Hầu hết các lệnh MCP IMAP chỉ thực hiện tra cứu, đọc và tóm tắt. Tránh cấp quyền gửi/xóa mail nếu không thực sự cần thiết để bảo vệ inbox.
